# Metin2 Launcher

Sıfırdan yapılmış tertemiz Metin2 Launcher uygulaması!

## Özellikler
- ✨ Şık Metin2 temalı arayüz
- 🚀 Winlator'ı arka planda motor olarak kullanır
- 📱 Otomatik izin yönetimi
- 🎮 Tek tıkla oyun başlatma

## Kurulum
1. Android Studio'da projeyi aç
2. Metin2 logosunu `app/src/main/res/drawable/metin2_logo.png` olarak ekle
3. Build et ve APK'yı kur

## Kullanım
- Telefonuna Winlator kur
- Winlator içinde "Metin2" adında container oluştur
- Launcher'ı aç ve "OYUNU BAŞLAT" de!

## Yapı
- **MainActivity.java**: Ana mantık ve Winlator entegrasyonu
- **activity_main.xml**: Şık arayüz
- **AndroidManifest.xml**: İzinler ve ayarlar

Bu senin uygulaman! İstediğin gibi değiştir, özelleştir. 😎
