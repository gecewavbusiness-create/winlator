# GecoMT2 Launcher

Sıfırdan yapılmış tertemiz GecoMT2 Launcher uygulaması!

## ✨ Özellikler
- 🎮 GecoMT2 özel tek APK launcher
- 🚀 Winlator'ı arka planda motor olarak kullanır
- 📱 Otomatik izin yönetimi (Android 11+ destekli)
- � Crash-proof .desktop dosyası oluşturma
- 💫 Akıllı UI durumları ve hata yönetimi
- 🪄 Arka plana geçme illüzyonu

## 🚀 Kurulum
1. Android Studio'da projeyi aç
2. GecoMT2 logosunu `app/src/main/res/drawable/metin2_logo.png` olarak ekle
3. Build et ve APK'yı kur

## 🎮 Kullanım
1. Telefonuna Winlator kur (GecoMT2 Engine olarak)
2. Winlator içinde D: sürücüsünü `/storage/emulated/0/Metin2` olarak ayarla
3. GecoMT2.exe dosyasını `/Metin2/` klasörüne koy
4. Launcher'ı aç ve "GECO MT2 BAŞLAT" de!

## 📁 Yapı
- **MainActivity.java**: Optimize edilmiş GecoMT2 mantığı
- **activity_main.xml**: Şık GecoMT2 arayüzü
- **AndroidManifest.xml**: Gerekli izinler
- **strings.xml**: GecoMT2 branding

## ⚙️ Winlator Ayarı
- **Container Settings → Drives**
- **Letter:** `D:`
- **Path:** `/storage/emulated/0/Metin2`

## 🎭 İllüzyon
Kullanıcı tek bir uygulama görür:
- **Launcher:** "GecoMT2" 🎮
- **Engine:** "GecoMT2 Engine" (Winlator modlanmış) ⚙️🎮

Bu senin GecoMT2 Launcher'ın! İstediğin gibi özelleştir. 😎
